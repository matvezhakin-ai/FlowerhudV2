# Flower hud

Круговое лепестковое меню конвертации файлов для Windows.

Клик колесиком мыши по любому файлу (в проводнике или на рабочем столе) — распускается цветок с форматами. Выбрал формат — файл сконвертирован в ту же папку. Можно выделить хоть 50 файлов — цветок конвертирует все разом.

## Установка

Скачай **FlowerHud.exe** (Windows 10) или **FlowerHud-win11.exe** (Windows 11) со [страницы релизов](https://github.com/matvezhakin-ai/FlowerhudV2/releases/latest) и запусти. Всё:

- приложение повиснет в фоне (значок в трее)
- само пропишет автозапуск вместе с Windows
- (опционально) `RadialShell.exe install` — добавит пункт «Radial Menu» в правый клик по файлам

## Как пользоваться

1. Кликни колесиком мыши по файлу (или по пачке выделенных)
2. В центре — текущий формат или число выбранных, на лепестках — целевые форматы
3. Для JPG — круговой ползунок качества вокруг центра: крути колесиком, клик — старт
4. Готово: новые файлы лежат рядом с исходниками

ESC или клик мимо цветка — закрыть меню.

## Форматы (v1.1)

| Категория | Форматы |
|---|---|
| Картинки | PNG · JPG (качество 50–100%) · BMP · GIF · TIFF · ICO · WMF · EMF |
| Видео | MP4 · AVI · MKV · WEBM · MOV → MP3 · WAV · GIF (через ffmpeg) |
| Аудио | MP3 · WAV · OGG · M4A · FLAC (через ffmpeg) |
| Таблицы | XLSX · CSV · TSV → PDF · DOCX (Word) · HTML |
| Текст и код | TXT · MD · JSON · HTML · 40+ языков кода → PDF · HTML · TXT · MD |

Для видео и аудио нужен [ffmpeg](https://ffmpeg.org/download.html) в PATH.

## Технологии

- **C# WPF (.NET 8)** — интерфейс, анимации, конвертация, OOXML-генерация
- **C++ (MinGW)** — интеграция в проводник Windows
- Отдельные сборки под Windows 10 и Windows 11
