# Flower hud

Круговое лепестковое меню конвертации файлов для Windows.

Клик колесиком мыши по любому файлу (в проводнике или на рабочем столе) — распускается цветок с форматами. Выбрал формат — файл сконвертирован в ту же папку.

## Установка

Скачай **FlowerHud.exe** из этого репозитория и запусти. Всё:

- приложение повиснет в фоне (значок в трее)
- само пропишет автозапуск вместе с Windows
- (опционально) `RadialShell.exe install` — добавит пункт «Radial Menu» в правый клик по файлам

## Как пользоваться

1. Кликни колесиком мыши по файлу
2. В центре покажется текущий формат, на лепестках — целевые
3. Выбрал формат → готово, файл рядом с исходником

ESC или клик мимо цветка — закрыть меню.

## Форматы

| Категория | Форматы |
|---|---|
| Картинки | PNG · JPG · BMP · GIF · TIFF (встроено в Windows) |
| Видео | MP4 · AVI · MKV · WEBM · MOV → MP3 · WAV · GIF (через ffmpeg) |
| Аудио | MP3 · WAV · OGG · M4A · FLAC (через ffmpeg) |
| Текст и код | TXT · MD · CSV · JSON · HTML · логи и код на 20+ языках → HTML-документ / TXT / MD |

Для видео и аудио нужен [ffmpeg](https://ffmpeg.org/download.html) в PATH.

## Технологии

- **C# WPF (.NET 8)** — интерфейс, анимации, конвертация
- **C++ (MinGW)** — интеграция в проводник Windows
